✈️ Overbooking Optimizer

Some passengers won't show up, so an airline sells more tickets than seats. Sell too few and seats fly empty; sell too many and you pay to bump people. This page simulates 10,000 flights at every overbooking level from 0 to 20 extra tickets, and asks whether knowing each passenger's own no-show score beats one average rate for everyone.

Load a CSV with columns score (model's no-show probability) and no_show (0/1), e.g. HW4-larkspur_noshow_scores.csv. Each simulated flight draws its passengers from these bookings, with their real outcomes. The file stays in your browser.

How it works

Each flight gets seats + 20 potential passengers in booking order. Selling seats + k tickets means the first seats + k of them hold tickets. Bumped = max(0, shows − seats); empty seats = max(0, seats − shows); cost = bump cost × bumped + empty cost × empty. The same random flights are reused for every k (common random numbers), so differences between levels are real, not noise.

Fixed level: the k with the lowest average cost across all flights. That's the best any single rule can do. Per-flight with scores: before each flight the airline adds up its booked passengers' no-show scores and picks the k that minimizes that flight's expected cost, using the exact (Poisson-binomial) distribution of how many of them will no-show.
